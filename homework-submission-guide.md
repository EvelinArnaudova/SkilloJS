## Homework Submission Guide

This guide explains where to find each homework assignment and how to submit your completed solution.

### Where to find the assignment

Each lecture has its own homework assignment described in a Markdown file inside that lecture's `homework` folder.

```
lectures/<lecture-folder-name>/homework/homework-assignment.md
```

Example for Lecture 1:

```
lectures/01-development-env-basics/homework/homework-assignment.md
```

Read this file carefully before starting — it contains the exact tasks, requirements, and any file/folder naming rules for that lecture.

### How to submit your solution

Once you've completed the assignment, upload your solved homework to the **learning portal**. Do not submit homework through this repository or via GitHub.
